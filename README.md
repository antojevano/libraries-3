## 0git

#### 첫 번째 방법
1. [s-mananger-manager-g 웹 사이트](https://weak_attr_ac.github.io/s-mananger-manager-g)에 접속한다.
2. 정리된 내용 중 오탈자 또는 개선점을 찾는다.
3. 각 페이지 하단의 **Edit this page** 버튼을 클릭한다.

![contribution-guide](images/awesome-webxr.jpg)

4. 수정 후 PR을 생성한다.

#### 두 번째 방법
1. [노트 폴더](https://github.com/weak_attr_ac/s-mananger-manager-g/tree/master/notes)로 이동한다.
2. 수정이 필요한 파일을 찾는다.
3. 수정 후 PR을 보낸다.

기여는 언제나 환영합니다. 🙏
